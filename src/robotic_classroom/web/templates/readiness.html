DEPLOYMENT

Start with your Raspberry Pi.

The application runs alongside your camera, microphone and robot hardware. Your existing Pi is the starting point for private deployment.

    Run the Pi service

    Use the installed zee-robot service. Keep one application process in charge of the hardware.

  2. 02

    Choose private access

    Use your local network or an approved private network such as Tailscale. Validate video and audio from another network.

  3. 03

    Complete the acceptance checks

    Configure access tokens, test returning echo, and finish the supervised classroom pilot before production promotion.
